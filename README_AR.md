# مساعد النقر الميسر

تطبيق أندرويد بسيط ومناسب لقارئ الشاشة، يعتمد على Accessibility Service لتنفيذ نقرة في موضع محدد من الشاشة، ثم يمكنه تنفيذ سحب للأعلى بعد النقرة.

## الفكرة
- تضبط موضع النقر كنسبة من الشاشة: X أفقيًا و Y عموديًا.
- تضبط الفاصل الزمني بين الدورات.
- تضبط عدد الدورات قبل الإيقاف التلقائي.
- تفتح المتصفح أو أي تطبيق آخر.
- زر رفع الصوت يبدأ أو يوقف التشغيل.
- زر خفض الصوت يوقف فورًا.

## طريقة البناء في Android Studio
1. افتح Android Studio.
2. اختر Open.
3. اختر مجلد AccessibleTapHelper.
4. انتظر مزامنة Gradle.
5. من القائمة اختر Build ثم Build APK(s).
6. ستجد ملف APK داخل:
   app/build/outputs/apk/debug/app-debug.apk

## طريقة الاستخدام بعد التثبيت
1. افتح التطبيق.
2. اضغط: فتح إعدادات إمكانية الوصول.
3. فعّل خدمة: خدمة مساعد النقر الميسر.
4. ارجع للتطبيق واضبط الإعدادات.
5. افتح المتصفح على الصفحة المطلوبة.
6. اضغط زر رفع الصوت لبدء التشغيل أو إيقافه.
7. اضغط زر خفض الصوت للإيقاف الفوري.

## ملاحظات مهمة
- استخدم التطبيق للأغراض الشخصية والمسموح بها فقط.
- لا تستخدمه لتجاوز حماية المواقع أو تنفيذ نشاط مخالف لشروط أي خدمة.
- أقل فاصل زمني مسموح داخل التطبيق هو 1.2 ثانية لتقليل الأخطاء والنقرات غير المقصودة.
