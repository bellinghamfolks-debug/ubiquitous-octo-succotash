# بناء APK بدون Android Studio

هذا المشروع جاهز للبناء عبر GitHub Actions. بعد رفع الملفات إلى مستودع GitHub، سيُبنى ملف APK تلقائيًا ويمكن تنزيله من تبويب Actions.

الخطوات المختصرة:
1. افتح GitHub وأنشئ مستودعًا جديدًا.
2. ارفع محتويات هذا المجلد كاملة إلى المستودع.
3. ادخل إلى تبويب Actions.
4. شغّل Workflow باسم Build APK إذا لم يبدأ تلقائيًا.
5. بعد اكتمال البناء، افتح نتيجة التشغيل ونزّل Artifact باسم AccessibleTapHelper-debug-apk.
6. داخل الملف المضغوط ستجد APK جاهزًا للتثبيت.

ملاحظة مهمة:
بيئة هذه المحادثة لا تحتوي Android SDK ولا أدوات التوقيع والبناء، لذلك لا يمكن إنتاج APK نهائي داخلها مباشرة. هذا الملف يوفّر طريقة بناء جاهزة دون فتح Android Studio.
